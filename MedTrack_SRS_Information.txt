SOFTWARE REQUIREMENT SPECIFICATION (SRS) ON MEDTRACK – PHARMACEUTICAL INVENTORY AND EXPIRY MONITORING SYSTEM
1.0 PROBLEM DEFINITION
Pharmacy stores usually maintain a large number of medicines with different batch numbers, manufacturing dates, and expiry dates. In small and medium pharmacies, expiry checking and stock management are often done manually. This process is time-consuming and prone to human error.
Due to manual management:
Expired medicines may remain unnoticed.
Expired medicines might accidentally be sold to customers.
Pharmacy owners may suffer financial loss due to unsold expired stock.

The MedTrack system solves these problems by providing a digital inventory system with automated expiry monitoring and barcode-based billing. It is a software application developed to assist pharmacy shopkeepers in managing medicine inventory efficiently and monitoring expiry dates of medicines.

Main features of the system include:
The system stores and manages medicine information such as medicine name, batch number, manufacturing date, expiry date, quantity, barcode, and price.
The user can search medicines in the inventory using medicine name or barcode scanning.
The system automatically monitors expiry dates and categorises medicines as:
Expired
Expiring Soon
Safe
The system integrates a Point of Sale (POS) billing system using barcode scanning.
When a medicine is sold, the barcode is scanned, the bill is generated, and the inventory stock is automatically updated.
The system generates alerts for medicines nearing expiry to help pharmacy owners avoid losses.
2.0 SYSTEM REQUIREMENT SPECIFICATION
2.1 INTRODUCTION
2.1.1 Purpose The purpose of this Software Requirement Specification (SRS) document is to describe the functional and non-functional requirements for the development of the MedTrack Pharmaceutical Inventory and Expiry Monitoring System.
This document serves as a guideline for developers, testers, and stakeholders to understand the system's design and functionality.
2.1.2 Scope The product titled “MedTrack – Pharmaceutical Inventory and Expiry Monitoring System” is designed to help pharmacy shopkeepers manage medicine inventory and track expiry dates efficiently.
The system performs the following tasks: • Maintain digital records of medicines. • Monitor expiry dates automatically. • Generate bills using barcode scanning. • Update stock quantities after sales. • Provide alerts for medicines nearing expiry.

2.2 OVERALL DESCRIPTION
2.2.1 Product Perspective MedTrack is a desktop-based application designed for pharmacy shops to manage medicine inventory and monitor expiry dates. The system integrates inventory management with barcode-based for billing and expiring monitoring.
2.2.2 Hardware Interfaces • Computer or Laptop • Minimum 4 GB RAM • USB Barcode Scanner • Printer for bill printing • Keyboard and Mouse
2.2.3 Software Interfaces • Programming Language: Python • Database: MySQL • Development Environment: Visual Studio Code • Operating System: Windows
2.2.4 Operations The software provides the following operations: • User login and authentication • Medicine inventory management • Barcode-based POS billing • Automatic stock updates • Expiry monitoring and alerts
2.2.5 User Characteristics The intended users are pharmacy shopkeepers or pharmacy staff members. The system is designed to be user-friendly and easy to operate, requiring only basic computer knowledge.
2.2.6 Constraints • The system requires a barcode scanner and printer. • The system is designed primarily for Windows operating systems. • Users must remember their login credentials.
2.3 FUNCTIONAL REQUIREMENTS
The system shall perform the following functions:
User authentication through login credentials.
Add, update, and manage medicine inventory records.
Scan medicine barcodes for billing.
Generate customer bills.
Automatically update stock after sales.
Monitor expiry dates of medicines.
Display alerts for medicines nearing expiry.
Generate inventory reports.
2.4 NON-FUNCTIONAL REQUIREMENTS
Performance The system should process billing and inventory operations quickly.
Usability The system interface should be simple and easy to operate.
Security Only authenticated users should be able to access the system.
Hardware Requirements • Computer or laptop with minimum 4 GB RAM • USB barcode scanner • Printer for bill printing
2.5 USE CASE (MAIN INTERACTIONS)
Actor: Pharmacy Shopkeeper
Main interactions with the system: • Login to the system • Add and manage medicine records • Scan barcode to sell medicines • Generate billing receipt • View expiry alerts • View inventory reports
